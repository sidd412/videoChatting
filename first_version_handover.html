📢 Status Overview

🌐 1. System Components & Architecture (Simple Breakdown)

The system consists of three main components that communicate securely in the cloud to provide a smooth user experience:

📱 1.1 The Front-End (Android Application)

This is the actual app that users install on their phones. It is built using Kotlin & Jetpack Compose, Google's latest toolkit. It features a modern, fluid visual theme with glassmorphism layouts, full dark/light mode alignment, and smooth animations.

🖥️ 1.2 The Engine (Backend Server)

This is the central processor hosted on Render Cloud Services. It contains all the matchmaking logic, connects users together, coordinates chat logs, and manages database transactions securely.

💾 1.3 Caching & Database (Redis & MongoDB)

We use MongoDB to permanently save profiles, chat messages, and settings. In addition, we integrated Redis (an in-memory caching system). Redis works at lightning-fast speeds to find and pair matched users in milliseconds without any lag.

✅ 2. Implemented Features (Completed & Working)

  • Instant Live Video Calling: Integrated with Agora RTC to provide crystal-clear, HD video and audio calling with minimal delay, even on weaker network connections.
  • Real-Time Chatting: Instantly exchange text messages with read/delivered checkmarks and online status indicators. All logs are securely saved for future access.
  • Intelligent Match Preferences: Allows users to set criteria such as age limits, gender filters, and geographical boundaries to customize their matching pool.
  • Coin-Based Billing: A complete wallet system that calculates call duration. It checks balance before matching and automatically deducts coins every minute, disconnecting cleanly if the balance reaches zero.
  • Secure Payment Checkout: Integrated with Juspay Gateway. It launches a secure web payment form where users can purchase coin packs using UPI, credit cards, or net banking. Balance is updated automatically after payment completes.
